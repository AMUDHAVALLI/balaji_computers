# Sri Balaji Computers (SBC – System Doctor) | Puducherry CCTV & IT Website

A full-stack interactive CCTV, Laptop, and Computer business website and lead-generation platform built for **Sri Balaji Computers (Mudaliarpet, Puducherry - 7200113344)** using **React (Vite) + Tailwind CSS** on the frontend and **Node.js / Express + PostgreSQL** (with automatic local JSON fallback persistence) on the backend.

## Customer Acquisition Pipeline
`Website → Enquiry → Lead → Follow-up → Quotation → Sales → Installation`

1. **Complete Customer-Facing Website Pages with Dynamic Google SEO Meta Tags**:
   - **Home**: Styled after the official **Sri Balaji Computers** business card with the circular **SBC System Doctor** logo, interactive Live 3-Camera CCTV Feed Simulator (Day/ColorVu & Night IR toggle), Digital Business Card showcase, Puducherry service area selector (`Mudaliarpet`, `Thengaithittu`, `Puducherry Town`, `Lawspet`, `Saram`, `Villianur`, `Reddiarpalayam`), service cards, and embedded lead capture.

## Quick Start

### 1. Start the Backend API (`http://localhost:5000`)
```bash
cd backend
npm install
npm start
```

### 2. Start the Frontend (`http://localhost:5173`)
```bash
cd frontend
npm install
npm run dev
```
